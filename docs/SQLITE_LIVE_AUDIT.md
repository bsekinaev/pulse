# PULSE-018: read-only аудит существующей SQLite на VPS

Этот скрипт написан на стандартной библиотеке Python и может быть передан
через stdin в уже работающий контейнер ПУЛЬС `v0.1.0`. В нём используются
`mode=ro` и `PRAGMA query_only=ON`.

Выводятся **только** результат проверки целостности, хеш SQL-схемы,
ревизия Alembic и количества записей трёх таблиц. Имена сотрудников,
ответы, комментарии, пароли, токены и сами строки БД не выводятся.

## Выполнение на изолированной базе

```bash
python -m scripts.audit_sqlite_readonly --database /path/to/pulse.sqlite3
```

## VPS: чтение без обновления контейнера

После подтверждения исходника скрипта его можно передать в контейнер
`pulse-demo` как `docker exec -i pulse-demo python - --database
/var/lib/pulse/pulse.sqlite3`. Путь заранее известен из Compose.
Никаких `docker compose up`, `docker restart`, `cp`, `git checkout`
или операций изменения томов не требуется.

Аудит **не заменяет** резервное копирование и тест восстановления на
отдельном стенде. Операции записи, пересоздания контейнеров и migration
production до релизной приёмки по-прежнему запрещены.
