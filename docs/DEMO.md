# Демонстрация до трёх минут

**0:00–0:20** — Боль бизнеса: новичок может столкнуться с препятствием, которое руководитель обнаружит слишком поздно.

**0:20–0:40** — Открываем HR-панель. Показываем восемь синтетических сотрудников, открытые проблемы и отсутствующие ответы.

**0:40–1:15** — Открываем карточку Алексея, затем мобильную анкету. Указываем, что не выдан терминал ТСД.

**1:15–1:45** — Отправляем обратную связь и показываем новую проблему на панели руководителя.

**1:45–2:20** — Открываем карточку проблемы и закрываем с текстом решения «Терминал выдан, доступ проверен».

**2:20–2:40** — Показываем изменение счётчиков и историю результата.

**2:40–3:00** — GitHub Actions, тесты, ссылка на код. Честно отмечаем, что Битрикс24 не подключён.

Не показывайте реальные токены, пароли, персональные данные и секреты.
