# PULSE-017 — начальная миграция Alembic для v0.2.0

Добавлена **базовая миграция** `20261111_0001` со структурой SQLite v0.1.0.

## Возможные состояния

- **Пустая БД:** Alembic создаёт таблицы и записывает номер ревизии.
- **Существующая БД v0.1.0 без номера ревизии:** сначала проверяются
  набор таблиц, столбцы, внешние ключи и уникальные ограничения.
  Совместимая структура помечается базовой ревизией; данные сохраняются.
- **Существующая БД с ревизией:** применяется `upgrade head`.
- **Несовместимая БД:** выполнение останавливается без маркировки.

## Локальная проверка

```bash
python -m scripts.migrate_sqlite --database-url sqlite:///./pulse.sqlite3
python -m pytest -q tests/test_migrations.py
```

**На VPS этот скрипт пока не запускать.** Сначала необходимы:
1. Согласованный backup исходной базы.
2. Restore на отдельном стенде.
3. Проверка совместимости с реальной копией схемы.
4. Отдельное релизное решение по обновлению контейнера и базы.

В v0.1.0 приложение использует `create_all()`. До релизного кандидата
v0.2.0 этот механизм будет заменён проверкой управляемой схемы в production.
Данная миграция — только безопасный первый этап.
